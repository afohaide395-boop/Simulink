# 本次上传模型的整理说明

当前交付为根目录的reduce_emf_tidy.slx；全部代码已嵌入SLX，不需要安装脚本。输入备份tests/fixtures/reduce_emf_user_cleanup.slx是本次用户上传文件的逐字节副本。

## 三个主要示波器

都放在顶层“运行监测”中，原21个Scope减少为3个：

1. 电机与观测器_角度及误差对比：四个显示区分别为电角度、实际角度差、实际FOC角度差与两组辨识角度、实验阶段。
2. 参数辨识_电感与磁链：分别显示H和Wb，直接连接真正的第3/4输出。
3. 电机运行_三相电流转矩转速：保留判断启动与运行是否正常所需的基本波形。

Scope停止时自动缩放坐标，图例标明通道名称和单位。

真实电角度由电机测量总线的Rotor angle thetam乘Np得到，原信号链已经做过这次转换，新的监测不再重复乘极对数。PLL观测角取PLL本身输出；FOC控制角取实际进入Park变换的同一条信号。两种误差都按“真实电角度减观测角”计算：

```matlab
atan2(sin(theta_real-theta_hat),cos(theta_real-theta_hat))
```

结果位于[-pi,pi]，跨2pi不产生伪跳变。FOC与PLL的角度信号之间有原有一拍延迟，因此同时保留两种实际误差。辨识角度应重点与FOC角度误差比较。

辨识A/B是两组工作点的基准误差。虚拟反电动势注入期间，实际误差含额外偏移；结合阶段2、6及相应稳态窗口比较，不能要求两条保持的辨识角度在所有阶段都与实际曲线重合。真实角度仅用于监测，不接入观测器、控制或辨识回路。

## 辨识代码精简

完整源文件为fcn.m，对照的fcn_before.m仅把上传代码主函数名改名用于独立回放。

保留原来的ud0/ud1/ud2、ud00/ud11/ud22等分段数组命名、switch(stage)、差矢量低通、逐点回归、粒子/样本双重循环。没有三维数据缓存、H/h/yy二次型目标函数或新的辅助函数。

保持本次上传版本的1Hz差矢量滤波、外部五路50Hz低通、100us周期、六段采样、30粒子、150代、初始散布与学习系数。

精简内容：

- 删除正负注入段从未使用的12个电流/转速缓存。
- 删除由当前k已经能够确定的两个重复采样计数及重复条件。
- 每组采齐后只按最终角度构造一次y/a/b，删除会被最终值覆盖的中间b计算及重复更新。
- 删除1e-9差矢量幅值门限，保留“矢量不能严格为零”的数学定义保护。
- 将1e30适应度初值改为Inf，移除这一人为数值上限。

保留采样边界、数据齐备、新实验复位、PSO代数控制和非有限输入保护；这些用于防止越界或使用缺失数据。没有给电感/磁链添加正值或物理范围钳制。

## 接线清理

四路输出依次为dtheta、dtheta1、Ls_hat、psi_hat。此前PID_Ls/PID_psi错接在1/2端口，本版改到3/4，并为1/2建立PID_da/PID_db。

删除没有来源的旧Rs、完成标志、RLS计数、运行码等显示和日志。param_identification现在记录四列：

```text
[dtheta dtheta1 Ls_hat psi_hat]
```

原始/滤波后采集记录和阶段记录保留。旧ack没有产生者，改用0经原UnitDelay接入PLL原确认口，维持既有固定时序，不改变PLL代码。电机原来没有外加负载，Tm从悬空默认零改为显式Ground零。两个既有HMI测点保留并终止，避免删除显示后出现悬空端口。

## 验证范围

validation_algorithm.txt：用同一组连续方程数据逐拍对照上传代码，覆盖六段采样、有符号角度、反转、电流差分、150代PSO及重启。正常记录下四路输出和每代随机状态逐位一致。

validation_small_vector.txt：删除1e-9门限后，微小非零电压差仍产生角度；基准数据缺失时不会伪造L/磁链。该数学测试不是低信噪比下的精度保证。

validation_structure.txt：四输出和四列日志对应，所有From有来源，195个可见及封装信号端点检查通过；471个保留控制输入来源不变，原始电气连接树、电机参数、其他算法、初始化和求解器保留。三种故障注入可被检出：角度错接电感、Scope输入断线、Points写在Src之前。

validation_syntax.txt：辨识脚本和三份Scope配置表达式通过MATLAB语法解析；六入四出明确标量。
