# 四输出PSO辨识函数修正版

将[fcn.m](fcn.m)的完整内容替换到本次上传模型的“参数辨识与采集/参数辨识算法/参数辨识”MATLAB Function中。

函数签名不变：

```matlab
[dtheta, dtheta1, Ls_hat, psi_hat] = fcn(ud, uq, id, iq, we, stage)
```

输出1/2为两组有符号角度rad，输出3为电感H，输出4为磁链Wb。外部PID_Ls、PID_psi应接3、4端口；先前模型中把它们接到1、2端口的问题，替换函数本身不会自动修正。

本版是电感、磁链辨识，保留四输出接口。电阻辨识及旧的ack、状态、R0/V0等From/Goto接口需在模型层面另行处理，不能凭四输出函数给旧12列日志提供数据。

## 修改内容

- 计数器在阶段切换后再加一。每个6000拍阶段先等1000拍，再实际保存5000点，不循环覆盖同一段数据。
- 从5000个基准样本只构造4999个真实前向差分，不读取未采集的第5001点。
- 对正负注入电压差的两个分量分别做窗口平均，再取角。去掉abs，按论文反正切区间保留符号；两组角度分别锁存，不在普通阶段切换时清零。
- 删除额外0.01Hz差矢量滤波；本函数假设输入已经过原模型的五路同系数50Hz低通。
- 数据和角度齐备后，在stage9处理基准数据。每次调用处理A/B各一个点，全部4999对样本均参与论文的残差目标函数。
- PSO仍为30个粒子、150代、惯性权重0.7、学习因子1.5。每次调用运行一代，完成后保持结果，新的stage0或stage2重置整个实验。
- 将全部逐点残差平方和展开为二次型以计算适应度。没有改用均值回归，也没有用解析解取代PSO，省去每代每个粒子反复遍历全部存储样本的开销。
- 不做参数正负或物理范围钳制。未计算、缺数据或无法定义角度时显示NaN，不伪装成0或额定参数。非有限输入和阶段10中止本次计算。

初始化粒子的中心9mH、0.1Wb和散布沿用原代码，仅用于初始化，不是固定输出，也不是搜索边界。

## 调用时序

采样周期100us，各采样段stage2/3/4、6/7/8各6000拍。stage5为工作点恢复。采齐后让stage9持续执行：

- 前4999拍构造回归目标函数，约0.4999秒。
- 后150拍运行150代PSO，约0.015秒；这段时间发布每代已评价的最优估计。
- 因而stage9开始后约0.515秒输出最终结果。此前电感、磁链为NaN是正常状态。

保持新实验重置条件与既有PLL时序一致；若在stage9暂停或离开，计算不会自动在其他阶段继续。

## 验证

已在GNU Octave 9.4.0执行实际交付函数，包含不同电机参数、正反转、正负角度、电流前向差分、等效压降消元、150代实际更新、完成锁存、重新启动、缺数据和非有限输入。另用负电感的数学测试确认未钳制参数；它不是物理电机工况。目标函数展开与逐点残差求和的数值等价性也已检查。结果见[validation.txt](validation.txt)。

代码及测试通过MATLAB语法解析。当前环境没有MATLAB/Simulink，尚未进行MATLAB Function代码生成、模型编译或整机仿真。理想方程回放的误差不能作为实际模型的精度保证；正负注入期间电流和速度基本稳定的论文假设仍需由模型波形验证。
