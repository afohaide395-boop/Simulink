# 按原代码风格修正的PSO辨识函数

本版以用户最初贴出的分段数组代码为基础修改，完整替换文件为[fcn.m](fcn.m)。

保留原来的ud0/ud1/ud2、ud00/ud11/ud22等分段变量、switch(stage)采样结构、差矢量一阶低通、y_o/a_o/b_o逐点回归式、pbest/gbest命名及粒子与采样点的双重循环。没有H/h/yy二次型、三维dq缓存或regression/cost辅助函数。

fc=0.01Hz、30粒子、150代、初始散布、惯性权重及学习因子均沿用原代码；滤波截止频率是否适合当前电机仍需整机波形验证。

保留的正确性修正：

1. 阶段切换后再加计数，每段6000拍保存5000个真实点；超出采样窗口后不循环覆盖。
2. 5000点只生成4999个前向差分，不读取未采集的第5001点。
3. 去掉角度绝对值，保留符号并映射到[-pi/2,pi/2]；两组角度分别保持。
4. 各段采样点数用于确认数据齐备；缺段时不启动PSO。
5. 各组采完后，用最终角度更新该组B1_all或B2_all，避免不同回归点混用滤波过程中的不同角度。
6. PSO继续在阶段9每次调用更新一代，150代后保持结果；进入新的阶段0或2时清空旧数组、粒子和结果。

目标函数仍通过原来的for kk逐点计算两组残差平方和，不以二次型展开或均值替代。每代计算量高于此前二次型版；当前没有做100us硬实时执行时间验证。

输出顺序没有改变：

```matlab
[dtheta, dtheta1, Ls_hat, psi_hat]
```

角度单位rad，电感H，磁链Wb。外部电感、磁链标签应接第3、4端口。未计算的量为NaN。本次仅交付四输出辨识代码，不自动处理模型中遗留的From/Goto信号。

[validation.txt](validation.txt)记录GNU Octave实际函数回放：使用不同于粒子初始中心的电机参数、负电角速度、正负角度、变化电流及前向差分，执行完整150代，另核对角度保存、结果保持、重新启动及缺数据不辨识。

这不是MATLAB/Simulink编译或整机仿真；不以理想方程数据回放误差承诺整机辨识精度。
