# 永磁同步电机参数辨识 v7：先输出实际递推结果

模型 `reduce_emf_identified.slx` 已嵌入全部算法。需要兼容原模型的 MATLAB R2024b、Simulink 和 Specialized Power Systems；运行 SLX 不依赖外部 .m 文件，源文件用于审阅和测试。算法及验证脚本的文字注释均为中文。

## 本版按用户要求取消阻断门限

此前的 -6 表示注入段与同组基准段的电流或转速差异超限，旧逻辑会一直重试直至中止，因而没有参数结果。v7 改为调试流程：

- 原有 I/F 切换到无感后，等待固定 0.5 秒开始实验，不再等待额外的相位、速度趋势门限。
- 六个采样阶段每段固定 0.6 秒，Id 工作点切换阶段仍为 0.7 秒。
- 50 Hz 低通及五路相同的一电周期滑动平均保留；等待平均器填满，保存最先填满的 2000 点窗口，不因诊断不合格而重取窗口。
- 电压纹波/漂移、电流、转速、同组工作点、正负窗口匹配、位置误差大小、注入差幅值和回归条件数只记录提示，**不拒绝采样、不触发超时、不阻止递推**。
- 六段采齐后先处理两组位置误差，再按 A1、B1、A2、B2……A2000、B2000 的顺序逐样本执行 4000 次 RLS。每次调用只执行一次真实更新。
- 不按电感、磁链或电阻的正负和大小隐藏结果，不用额定参数替代结果；曲线显示实际采样数据得到的估计，即使数值偏离额定值也保留。
- Rs 去掉原来的相对可观测性门限，仅当消元分母与浮点零无法区分时保留 NaN，避免除零。分母正常时直接显示算出的 Rs。

保留必要的非有限输入、缺失数据及浮点除零保护。它们用于避免无定义运算，不是精度验收。未计算或无法定义的参数仍为 NaN，不伪造一个正常数值。

## 看运行状态和参数曲线

打开 `参数辨识与采集`：

- **注入与采样阶段**：0 等待无感；2/3/4 第一组无、正、负注入；5 切换 Id 工作点；6/7/8 第二组无、正、负注入；9 计算。10 只用于数值错误中止。
- **辨识运行状态码**：0 等待，1 采集，2 角度处理，3 逐样本递推，**30 表示 4000 次递推完成**。
- **诊断提示_不阻断递推**：保留首个诊断提示。这里即使显示 -6，也不会让运行码变成 -6，不会影响参数输出。-3/-13 电压漂移/纹波，-4/-5 电流/转速，-6 同组工作点，-12 正负工作点，-7 注入或角度，-8 条件数，-11 Rs 分母无法求值。
- **RLS 已更新样本数**：从 1 递增至 4000，对应电感、磁链及 Rs 的实际迭代曲线。
- **L磁链计算完成_Rs_Rs已计算**：两侧标志只表示数值计算完成，不表示通过物理合理性或精度验收。

请关闭旧模型，再打开下载的新版，避免仍在运行旧的门限版本。正常切换至无感后约 5.3 秒可以完成采样和递推；模型默认时长保留 25 秒。

## 保留的数学关系

| 论文 | 实现 |
|---|---|
| 图12.9 | 虚拟电压只加到 PLL 使用的 d 轴反电动势，不直接叠加电机电压命令 |
| 式12.25 | 分别利用每组正负注入电压差估计位置误差，采用 ±π/2 的 atan 比值分支 |
| 式12.26～12.27 | `v=uq*id-ud*iq`，`lambda=we*(id^2+iq^2)`，`eta=we*(id*cos(delta)+iq*sin(delta))` |
| 式12.28 | 两个 Id 工作点的数据交替进入 `v=lambda*Ls+eta*psi` 的逐样本 RLS |
| 式12.29～12.32 | 当前 L/磁链结合两组 q 轴方程消去共同逆变器误差项，逐次计算 Rs |

RLS 数值更新保留：`theta=[Ls/0.01;psi/0.2]`，初始估计 0、P0=10I、遗忘因子 1，逐行归一化及 Joseph 协方差更新。不先批量求解再伪装成递推曲线。

Rs：`z_k=uq_k-we_k*L*id_k-we_k*psi*cos(delta_k)`，`D_k=(4/pi)*iq_k/hypot(id_k,iq_k)`，`R=(D_B*z_A-D_A*z_B)/(D_B*iq_A-D_A*iq_B)`。仅在 `abs(分母)>64*eps(max(消元项尺度,1))` 时执行除法，不再按相对分母门限或 Rs 物理范围屏蔽数值。

论文的稳态和工作点条件仍影响估计精度；本版按用户要求将它们从流程门禁改为记录项。计算完成不等于估计已经准确。若条件数差或工况变化，实际估计可能偏离，这些值仍会显示，以便下一步分析。

## 不改接线和原有调节器

保留整齐的分行短线布局、端口数、27 列结果、原有电气网络、电机/供电参数、速度 PI、iq 保持、I/F 启动、PLL 的 PI 与角度积分、100 微秒任务和求解器配置。PLL 中只修改实验启动和阶段推进逻辑；不将估计值反馈到电机控制。

所有现有低通仍为二阶 50 Hz、周期 100 微秒。函数内周期平均器每阶段锁存 `N=min(1257,max(50,round(2*pi/(max(abs(we),50)*Ts))))`，对五路使用同一窗口，并在阶段切换时清空历史；不会引入新的采样速率。

## 记录格式

`param_identification.signals.values` 仍为 27 列：

| 列 | 含义 |
|---|---|
| 1、2 | 两组位置误差/rad |
| 3、4 | 每次递推后的 Ls/H、磁链/Wb |
| 5 | L/磁链数值递推完成标志，非精度有效标志 |
| 6、7 | 当前 Rs/Ω、Rs 是否已算出有限数值 |
| 8 | 运行状态，30 为递推完成 |
| 9 | 回归矩阵条件数，仅记录 |
| 10、11 | 电压半窗均值漂移、同组 dq 电流均值差 |
| 12、13 | 实际 RLS 更新数、归一化创新残差 |
| 14、15 | Rs 消元分母相对量、当前采样状态计数 |
| 16 | 当前阶段数据已保存确认；负数仅用于数值错误 |
| 17 | 首个诊断提示，不阻断流程 |
| 18、19 | 周期平均前 ud/uq 标准差/V，已过 50 Hz 低通 |
| 20、21 | 周期平均后 ud/uq 标准差/V |
| 22、23 | ud/uq 均值漂移与参考门限之比，仅记录 |
| 24、25 | ud/uq 剩余纹波与参考门限之比，仅记录 |
| 26、27 | 锁存的周期点数、最近采样阶段 |

`id_raw`/`id_filtered` 记录原始/50 Hz 低通后的 `[ud uq id iq we]`，现有 Scope 不变。`identification_state` 记录实验阶段，`id_iq_reference` 记录 `[原速度PI输出,保持后的iq,保持标志]`。
