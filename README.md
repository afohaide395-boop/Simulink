# 永磁同步电机参数辨识 v6：修复电压纹波误触发 -3

模型：`reduce_emf_identified.slx`。需要兼容原模型的 MATLAB R2024b、Simulink 和 Specialized Power Systems。全部辨识算法已经嵌入 SLX，运行模型不依赖外部 .m 文件；源文件与测试脚本用于审阅和验证，新增及修改代码的注释均为中文。`%#codegen` 是 MATLAB 编译指令，予以保留。

## 为什么上一版停在阶段 10，状态码一直为 -3

阶段 10 是超时中止，并不是正在采样。v5 将电压窗口的标准差和前后半窗均值漂移都记为 -3，任何一个超限持续到 3 秒就结束实验，保留最后失败码。

用户报告 ud 在 -3～-2 V、uq 在 45～45.5 V 附近波动，图中有稳定平台和残余纹波。v5 对接近零的 ud 使用最低 0.1 V 标准差门限，即使均值稳定，纹波仍可能使整个窗口不断被拒绝。只看截图不能证明纹波的确切频谱，故新增测试使用这个量级的合成输入，不冒充用户实际采样记录。

v6 在保持原 50 Hz 二阶低通的基础上，对 **ud、uq、id、iq、we 五路同时加入相同的一电周期滑动平均**，只用于辨识支路。实验阶段开始 0.1 秒后，根据滤波后的电角速度锁存长度：

```
N = min(1257, max(50, round(2*pi/(max(abs(we),50)*Ts))))
Ts = 100 微秒
```

长度对应约 50～1256 rad/s 的电角速度范围。该平均器直流增益为 1，对电频及整数倍电频纹波具有零点；长度取整、转速变化和非同步噪声会留下残差，因此平均之后仍须通过原稳态门限。N 每个阶段重新锁存，不在阶段内部不断改长度；阶段切换会清空历史，防止混入上一段注入数据。

- **-3**：电压前后半窗均值仍有过大漂移。
- **-13**：电周期平均后剩余电压纹波仍过大。
- 两项分别显示诊断比值，**原门限没有放宽**。电流、转速及正负窗口匹配检查继续保留。
- 线性慢漂移经过滑动平均只会延迟，不会消失；不能靠平均器把未稳态数据当作合格数据。

控制周期、任务配置、电机参数、PLL 的可执行代码、速度环、iq 保持、I/F 启动和电气连接均未修改。保持上一版分行短线布局，仅在采集面板下方增加整齐的诊断显示。

## 打开模型后看哪里

打开 `参数辨识与采集`：

1. **注入与采样阶段**：0 等待，2/3/4 为第一组采样，5 为工作点切换，6/7/8 为第二组采样，9 为计算，10 为中止。
2. **辨识运行状态码**：0 等待锁定，1 采集，2 角度处理，3 RLS，20 三参数有效，10 仅 L/磁链有效；负数为失败。此处的 10 与“采样阶段 10”不是同一信号。
3. **等待或拒绝原因**：采集期间可暂时出现负数，窗口合格后清零；连续 3 秒无合格窗口才中止。
4. **RLS 已更新样本数**：真正执行递推时从 1 增加至 4000。
5. **新增电压诊断区**，每组依次为 d/q 两轴：
   - 周期平均前电压 RMS：这里的输入已经过原 50 Hz 低通。
   - 周期平均后电压 RMS：真正用于稳态检查及保存的数据。
   - 电压慢漂移与门限之比：两项均应不大于 1。
   - 剩余纹波与门限之比：两项均应不大于 1。
   - 周期点数及最近采样阶段：依次是 N 和中止前的采样阶段；阶段变成 10 后仍保留，便于查出具体失败在哪一段。

未计算的 L、磁链和 Rs 保持 **NaN**，有效标志为 0；不预填额定值，也不强制置有效。NaN 只出现在监测结果中，不反馈到电机控制。

其它等待/失败码：-1 非有限输入，-2 缺采样，-4 电流不稳，-5 转速不稳，-6 同组工作点变化，-7 注入电压差不足/角度异常，-8 回归病态，-9 最终估计非物理，-10 实验中止，-12 正负注入窗口电流/转速不匹配。

## 与论文原理的对应

| 论文 | 模型实现 |
|---|---|
| 图12.9 | 虚拟电压只加到 PLL 使用的 d 轴反电动势，不直接叠加电机电压命令 |
| 式12.25 | 在每个 Id 工作点采集无、正、负注入数据，由正负平均电压差估计各自位置误差，使用 atan 比值对应的 ±π/2 分支 |
| 式12.26～12.27 | 基准数据逐点构造 `v=uq*id-ud*iq`、`lambda=we*(id^2+iq^2)`、`eta=we*(id*cos(delta)+iq*sin(delta))` |
| 式12.28 | 两个不同 Id 工作点消除缺秩；按 A1、B1、A2、B2……A2000、B2000 顺序执行 4000 次真实 RLS 更新 |
| 式12.29～12.32 | 用当前 L、磁链及两组位置误差，由两组 q 轴方程消去共同逆变器误差项求 Rs，并独立检查可观测性 |
| 文献50 Hz滤波 | 原五路相同的二阶低通保留；v6 额外的同窗口电周期平均是针对残余纹波的工程处理，不能说成论文明确给出的参数 |

回归关系是 `v=lambda*Ls+eta*psi`。RLS 对 `[Ls/0.01;psi/0.2]` 作数值缩放，初始估计为 0、P0=10I、遗忘因子为 1，逐行归一化并采用 Joseph 协方差更新。参数不会先批量求解再伪装成递推曲线。平均后相邻样本有关联，因此协方差不解释为统计置信区间。

Rs：设 `z_k=uq_k-we_k*L*id_k-we_k*psi*cos(delta_k)`，`D_k=(4/pi)*iq_k/hypot(id_k,iq_k)`，则 `R=(D_B*z_A-D_A*z_B)/(D_B*iq_A-D_A*iq_B)`。使用了平衡正弦电流的平均扰动因子，分母过小时仅报告 L/磁链有效。

这些关系要求近似稳态；正负注入的电流和速度还必须匹配。滤波不能补救真实加减速，也不能恢复上游已混叠的信息。

## 采样与递推时序

- 0：等待 I/F 切换至无感，PLL 平均相位与速度趋势稳定 0.5 秒。
- 2、3、4：Id 偏移 0 A，依次无、正、负虚拟注入。
- 5：Id 改为 -1 A，恢复速度调节等待 0.7 秒；不保存辨识数据。
- 6、7、8：Id 偏移 -1 A，再采无、正、负注入。
- 每段至少等待 0.2 秒且周期平均器已填满，再检查最新 0.2 秒的 2000 点窗口。因此每段最少约 0.4 秒，低速时可能略长。仍按 100 微秒更新数据和执行函数，不引入新采样速率。
- 电压、电流、速度标准差及半窗漂移通过后，再检查工作点一致性；负注入窗口必须与已保存的正注入窗口匹配。
- 电流差不得超过 `max(0.003 A,0.0005*电流幅值)`；速度差不得超过 `max(0.02 rad/s,0.0001*|we|)`。不符合时继续滚动取窗。
- 窗口合格后，确认经明确的一拍延迟送至 PLL，才推进下一状态。一个状态超时 3 秒仍不合格则中止注入并恢复正常控制。
- 状态 9 用 0.04 秒处理两组位置误差，再用 0.4 秒完成 4000 次逐样本 RLS，随后保留结果，不无限重放同一批数据。

每组开始锁存对称虚拟注入幅值 `min(0.6,max(0.2,0.01*abs(Eq_hat)))` V。阶段 2～4、6～8 保持进入该组之前的速度 PI iq 输出，同时暂停 PI 误差输入，避免积分累积；0、5、9、10 恢复调节。模型时长为 25 秒。阈值、时长及幅值均为工程初值，仍应以整机记录检验。

## 记录格式

`param_identification.signals.values` 从 17 列扩展到 **27 列**，前 17 列含义保留：

| 列 | 含义 |
|---|---|

| 6、7 | 当前 Rs/Ω、Rs 最终有效标志 |

| 11 | 同组 dq 均值偏差最大值/A |
| 12 | 实际 RLS 更新数 |
| 13 | 当前归一化创新残差 |
| 14 | Rs 消元分母相对量 |

`id_raw`/`id_filtered` 仍记录原始/50 Hz 低通后的 `[ud uq id iq we]`；现有原始/低通对比 Scope 保留，不将它们误标为新增周期平均后的波形。新周期平均效果由诊断 RMS 比较，完整诊断随结果向量记录。`identification_state` 为实验阶段，`id_iq_reference` 为 `[真实速度PI输出,保持后的iq,保持标志]`。原始记录同样为 100 微秒，不能用于分析 10 kHz 载波频谱。

当前环境 **没有 MATLAB/Simulink**，不能宣称 SLX 已通过实际编译、整机启动或参数收敛。

已执行实际 .m 函数的 GNU Octave 测试，包括：用户波动量级的稳定平台、不同正负转速的电频/六倍频大纹波、真实慢漂移、非同步残余纹波、理想/噪声/缺秩/缺采样/电流不匹配/延后稳态、PLL 采样确认，以及同速率低通→周期平均→RLS 集成。另以真实 v5 代码复现同一稳定纹波输入的 -3，并对照 v6 的合格确认。合成输入不能代替用户电机的实际仿真记录。
