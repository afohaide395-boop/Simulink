# PMSM参数辨识 v5：闭环接线、采样确认与逐样本RLS

模型：`reduce_emf_identified.slx`。需要兼容原模型的MATLAB R2024b、Simulink和Specialized Power Systems。全部算法已嵌入SLX，不依赖外部.m文件运行；.m文件用于审阅和独立验证。

## 本次查出的实际错误

上一版把I/F选择后的`iq_ref`回接到“辨识iq保持”输入，漏接真正的速度PI输出。这不是有效的速度闭环。v5恢复为：

```
速度PI输出 → iq保持（正常时直通） → I/F选择的无感输入
IF启动Iq=7A ───────────────────→ I/F选择的启动输入
```

I/F选择后的`iq_ref → iq_give`原有通路恢复；不再从选择器输出回接其输入。保持标志释放时，iq立即重新跟随速度PI输出。

截图中的扇形线与缺失的分支主干走线信息有关。采集区已改成无分叉的点对点线：原始输入→原始标签、From→低通→滤波标签、From→RLS。剩余iq保持分支补全主干几何信息并将其置于Branch之前，不再依赖编辑器默认的(0,0)分支点。示波器仍在独立监测区。

电源负端、正端及三相电机的五条电气连接继续与原模型一致；电气线与信号线分别检查，避免再次误删Src-only电气支路。

## 与论文原理的对应

| 论文 | 模型实现 |
|---|---|
| 图12.9 | 虚拟电压只加到PLL使用的d轴反电动势，不直接叠加在电机电压命令上 |
| 式12.25 | 在每个d轴工作点分别采集无、正、负注入数据；由正负两段平均电压差求该组位置误差，使用atan比值对应的±π/2分支 |
| 式12.26～12.27 | 基准数据逐点构造 `v=uq*id-ud*iq`、`lambda=we*(id^2+iq^2)`、`eta=we*(id*cos(delta)+iq*sin(delta))` |
| 式12.28 | 使用两个不同d轴工作点消除缺秩；依次输入A1、B1、A2、B2……A2000、B2000，执行4000次真实RLS更新 |
| 式12.29～12.32 | 用当前L、磁链及两组各自的位置误差，由两组q轴方程消去共同逆变器误差项，计算Rs；Rs有独立可观测性检查 |
| 文献50Hz滤波要求 | ud、uq、id、iq、we均用相同的二阶50Hz低通，周期都是实际源信号的100μs |

具体回归关系是：`v=lambda*Ls+eta*psi`。RLS以`[Ls/0.01;psi/0.2]`作数值缩放，初始估计为0、P0=10I、遗忘因子1，逐行归一化并采用Joseph协方差更新。真实电机参数不被预填到估计器，也不用于钳制结果。

Rs计算从两组q轴方程出发。设`z_k=uq_k-we_k*L*id_k-we_k*psi*cos(delta_k)`，`D_k=(4/pi)*iq_k/hypot(id_k,iq_k)`，则`R=(D_B*z_A-D_A*z_B)/(D_B*iq_A-D_A*iq_B)`。这里使用了平衡正弦电流的平均扰动因子，并允许两组基准点使用各自测得的转速、iq。分母过小时只报告L/磁链有效，不伪造Rs。

这些关系的前提是电流近似稳态，正负注入的电流及转速应匹配；仅“波形平滑”或“等了固定时间”不足以满足式12.25。

## 采集改为确认后推进

状态仍是`0→2→3→4→5→6→7→8→9`；10为中止状态。

- 0：等待原有I/F切换至无感，PLL平均相位与速度趋势稳定0.5s。锁定判据使用滤波均值和相位均方值，避免原来要求原始瞬时误差连续5000点不过线而始终不触发。
- 2、3、4：Id偏移0A，依次无、正、负虚拟注入。
- 5：Id切换到-1A、恢复速度调节等待0.7s；不保存辨识数据。
- 6、7、8：Id偏移-1A，再采无、正、负注入。
- 每个采样状态先等待0.2s，再检查最新0.2s的2000点窗口。因此最短0.4s，但不是到点就切换。检查电压/电流/速度方差、前后半窗漂移和工作点一致性；未合格则继续滚动取窗。
- 负注入窗口还必须与已保存的正注入窗口匹配：dq均值差不超过`max(0.003A,0.0005*电流幅值)`，速度均值差不超过`max(0.02rad/s,0.0001*|we|)`，否则继续取窗，原因码-12。这用于约束式12.25中的相减条件。
- 窗口合格后返回当前状态编号，经明确的一拍延迟送给PLL，PLL才推进下一状态。一个采样状态超过3s仍无合格窗口，则返回负确认、中止注入并恢复正常Id/iq控制。
- 状态9用0.04s处理两组位置误差，再用0.4s完成4000次逐样本RLS；之后保留最终结果，不无限重复同一批记录。

每组三段开始时锁存虚拟注入幅值：`min(0.6,max(0.2,0.01*abs(Eq_hat)))` V，正负对称。它比之前约7%幅值小，降低恒定iq实验下的转矩/机械速度扰动。等待时间、阈值和幅值是针对该模型的工程初值，必须用实际采集记录验证，不是论文给出的通用常数。

状态2～4、6～8保持进入该组之前的速度PI iq输出，并暂停速度PI误差输入，避免积分累积；0、5、9、10恢复调节。原有I/F输入、PI系数、电机、PWM及供电参数保留。PLL的PI/角度积分和原观测器方程不变；仅改锁定监测、实验时序及采样确认。

模型默认仿真时长改为25s，给滚动窗口重试留余量。五路滤波仍是100μs同速率低通，不能恢复上游已混叠的信息；没有关闭多任务或降低速率错误诊断。

## 如何看结果，而不是看到一排零

打开`参数辨识与采集`，已有以下数值显示及状态说明：

- **注入与采样阶段**：当前0/2/3/4/5/6/7/8/9/10。
- **辨识运行状态码**：0等待锁定，1采集，2角度处理，3RLS，20三参数有效，10仅L/磁链有效；负数为失败。
- **等待或拒绝原因**：-3电压不稳，-4电流不稳，-5转速不稳，-6同组工作点变化，-12正负两段电流/转速不匹配；等待时仍会继续采集，超过3s才中止。
- **RLS已更新样本数**：只有真正执行递推才从1增加到4000。

未计算的L、磁链和Rs显示**NaN**，有效标志为0，不把初始化零当作辨识结果。NaN只在监测结果里，不送入电机控制。失败仍有明确状态和原因；不能仅把NaN改成额定值或强制置有效来让曲线看起来成功。

`param_identification.signals.values`共17列：

| 列 | 含义 |
|---|---|
| 1、2 | 两组位置误差，rad |
| 3、4 | 每次RLS更新后的Ls/H、磁链/Wb |
| 5 | L/磁链最终有效标志 |
| 6、7 | 当前Rs/Ω、Rs最终有效标志 |
| 8 | 运行状态码 |
| 9 | 归一化回归矩阵条件数 |
| 10 | 当前窗口电压半窗均值漂移最大值/V |
| 11 | 同组dq均值偏差最大值/A |
| 12 | 实际RLS更新计数 |
| 13 | 当前归一化创新残差 |
| 14 | Rs消元分母相对量 |
| 15 | 当前采样状态计时周期数 |
| 16 | 采样验收确认，正数=该阶段合格、负数=该阶段中止 |
| 17 | 最近窗口等待/拒绝原因 |

其它运行错误：-1非有限输入、-2缺采样、-7注入差不足/角度异常、-8回归病态、-9最终估计非物理、-10实验中止。

`id_raw`/`id_filtered`均为`[ud uq id iq we]`，`identification_state`记录阶段，`id_iq_reference`记录`[真实速度PI输出,保持后的iq,保持标志]`。原始记录也是100μs，不能用它分析10kHz载波频谱。ud/uq、id/iq的原始/低通对比Scope均保留；err1/err2仍为400点位置误差处理曲线。
