# PMSM 虚拟反电动势参数辨识 — v4（恢复启动电源回路）

模型：`reduce_emf_identified.slx`，原附件由MATLAB R2024b Update 8保存；需要兼容的Simulink与Specialized Power Systems。

## v4启动回归修复

v3整理顶层连线时误删了“直流电源负端—逆变桥DC负端—地”的电气连接树，断开了供电回路。这与用户报告的三相电流、转矩和转速全为零一致。电气分支允许所有端点都使用Src记录而没有Dst；之前把信号线的删除规则用于电气线，导致这条合法支路被误判为无目标连线。

v4只把原模型这条电气支路原样补回，包括分支类型、端点和保存的走线。没有继续更改I/F选择、iq保持、50Hz低通、采样率、RLS或子系统布局。与原始可运行模型逐一比对，DC正负端及三相输出共五条电气连接树、供电/桥/电机/地/powergui与I/F启动块参数均一致。

新增`check_power_connections.py`电气拓扑回归检查，可在仓库中运行：

```bash
python check_power_connections.py --self-test
```

该检查会验证当前模型，并确认上一版缺失DC回路的模型确实无法通过。它检查电气支路中的所有Src/Dst端点，不再要求电气线必须有Dst。这里验证的是拓扑与启动指令连接；当前环境仍没有MATLAB/Simulink，未实际运行电机启动仿真。

## 已有的采集修正与布局

用户实际编译确认：Park的id/iq、d/q电流环电压命令和速度接口都按100μs更新。v2把这些信号直接送入1μs低通，且没有跨任务数据传输处理，是实现错误。把慢速信号再送入快速滤波，也不构成采样前抗混叠。v2对此处“抗混叠”的描述和测试条件不适用于实际模型接口，本版予以更正。

- 五路二阶Butterworth低通改为`SampleTime=Ts=100μs`，**系数中的周期也全部由Tsim改成Ts**，保持截止频率50Hz；不是只修改采样时间而遗留1μs系数。
- 去掉滤波后重复的零阶保持。五路源、低通、RLS统一控制周期；此位置没有新增的快慢任务传输。
- 保留原求解器、多任务设置和`MultiTaskRateTransMsg=error`，没有通过关闭任务或改成警告掩盖问题。
- 顶层新增部分收拢为`参数辨识与采集`和`辨识iq保持`两个子系统，顶层块数由179降为147。第一模块有六路排列输入：ud、uq、id、iq、we、state；内部按“低通→RLS→结果/监测”分区。第二模块按“iq通道→状态使能→记录”分区。
- 监测支路使用子系统内的局部Goto/From，重排为正交短连线；取消重复的原始电压/电流小Scope，其内容保留在原始/低通对比Scope和工作区记录中。对新增的两个子系统按保存的块坐标和连线路径检查：无块矩形重叠、无连线穿过其他块内部。
- 移动MATLAB Function块后同步更新了Stateflow实例路径及SLX系统关系。RLS运算、4000次逐样本更新、采集时序和有效性检查保留v2实现。

## 保留的逐样本RLS流程

保留v2的逐样本RLS实现；两组采样数据交替补足回归方向，不以均值一次求出电感和磁链。

- 六段数据用于保留两个电流工作点及正负虚拟注入数据。正负注入数据按文献式12.25求得两组各自的位置误差；无注入数据按式12.26～12.28构造回归量。
- 存储数据按 `A1,B1,A2,B2,...,A2000,B2000` 交替输入，每100μs只执行一次RLS更新，输出当次的Ls、磁链与由其计算的Rs。共4000次更新，不重复循环同一批样本来制造收敛。
- 两组均值仅用于稳态检查、可观测性检查及Rs计算，不再用于直接求解Ls、磁链。不能因为某一单点欠秩就从同一工作点连续输入所有数据。
- 电感、磁链的初始估计为0，`P0=10*I`，遗忘因子1。回归量使用0.01H、0.2Wb作单位缩放并按行归一化，协方差用Joseph形式更新。这些是数值缩放，不是把真实参数预填到估计器。
- 估计值不被钳到8.96mH。最终范围检查只决定有效标志；不把异常结果伪装成通过。中间迭代值也照常输出。

## 滤波与稳态的实际边界

本版五路50Hz低通均作用于已有的100μs信号，属于同速率平滑，能衰减其奈奎斯特频率内的纹波。它不能恢复上游已经混叠、已经丢失的信息。若要真正消除采样前PWM混叠，需要另行设计对真实高采样率物理电流及坐标角度的同步采集；不能仅把现有100μs信号升采样来实现。本版不声称已经完成该上游改造。

每个采样状态仍持续0.7s：前0.5s等待，末0.2s保存2000点。采集前不能只凭等待时间判断稳态；仍检查电压、电流、速度标准差与前后半窗均值漂移，以及同一工作点三段数据的一致性。状态2～4、6～8保持iq指令并暂停速度PI误差输入，状态0、5、9恢复反馈。观测器、I/F、电流PI、速度PI系数/限幅、电机、PWM和求解器不变。

## 看什么信号

原ud/uq示波器仍看原始信号，因此即使辨识支路滤波有效，原示波器上仍会有纹波。

以下Scope和记录现在位于 `参数辨识与采集` 子系统内；iq参考记录位于 `辨识iq保持`：

- **`辨识ud_uq_原始与低通对比`**：四个输入依次为ud原始、ud低通、uq原始、uq低通。
- **`辨识id_iq_原始与低通对比`**：依次为id原始、id低通、iq原始、iq低通。
- **`辨识状态_条件数_迭代数_残差`**：来自结果向量第8～15列，列义见下表。
- 工作区记录`id_raw`和`id_filtered`：均为`[ud uq id iq we]`。`id_raw`记录也在Ts上，因此不能用它分析10kHz载波频谱；其作用是与滤波结果对齐比较。
- `id_iq_reference`：`[速度PI原iq指令, 保持后的iq指令, 保持标志]`。

`param_identification.signals.values`现在每行15列：

| 列 | 含义 |
|---|---|
| 1、2 | 第一、第二组位置误差，rad |
| 3 | 当次RLS电感估计，H |
| 4 | 当次RLS永磁体磁链估计，Wb |
| 5 | L/磁链最终有效标志 |
| 6 | 由当前L/磁链得到的Rs估计，Ω |
| 7 | Rs最终有效标志 |
| 8 | 辨识状态码 |
| 9 | 两工作点归一化回归矩阵条件数 |
| 10 | 六段采样窗口中最大的电压前后半窗均值差，V |
| 11 | 同一组三段中最大的dq电流均值偏差，A |
| 12 | 真实RLS更新计数，1～4000 |
| 13 | 当前归一化创新残差 |
| 14 | Rs消元分母相对量，过小则Rs不可观测 |
| 15 | 当前采样状态已执行周期数 |

状态码：0等待，1采集，2位置误差回放，3逐样本RLS，20三参数有效，10仅L/磁链有效；-1非有限输入，-2缺失采样，-3电压不稳，-4电流不稳，-5速度不稳，-6同组工作点不一致，-7注入差不足或角度异常，-8回归病态，-9最终结果非物理。

原状态时序仍为`0→2→3→4→5→6→7→8→9`。状态9先用0.04s逐步处理位置误差，再用0.4s完成4000次RLS更新。此后保留末次估计；本版是一轮有限数据辨识，不会在数据耗尽后无限重复同一批记录。观察迭代曲线时应放大状态9开始后的约0.45s，同时看第12列。RLS可能很快接近最终值，不能为了曲线看起来缓慢而人为平滑输出。原来的`err1/err2`保持400点诊断输出。

## 验证方式和已知边界

**当前云环境无MATLAB/Simulink：本版尚未完成MATLAB加载/编译与整机开关仿真，也没有复现用户实际运行得到的1.36mH。已根据用户给出的编译采样率修正五处接口；仍需实际MATLAB编译确认整个模型。不能把以下合成结果当成整机已经收敛的证据。**

已在GNU Octave 9.4.0直接执行交付的实际.m函数：11种辨识场景、1项PLL时序测试通过。测试检查每次RLS调用的迭代数只增加1，4000次输入均被消费，参数在递推过程中确实变化；缺采样、病态矩阵、电压漂移、电流变化和非有限值均正确拒绝。

v3额外使用与模型实际接口相同的100μs输入与低通系数进行合成数据集成测试：50Hz增益约-3dB，200Hz约-24.12dB；低通后的可分辨谐波数据送入实际RLS，4000次更新后Ls约8.95957mH、磁链0.209987Wb、Rs约1.86625Ω。这只是同速率滤波与算法测试，不是整机仿真。测试还显式确认：已在100μs信号中混叠成直流的10kHz成分不会被低通去除，防止再次将平滑误报成抗混叠。

在MATLAB中，把仓库文件放在同一目录，关闭已打开的旧版同名模型后执行：

```matlab
report = run_model_validation;
```

脚本会先运行算法自检，再编译模型并仿真10s。其在断言收敛前保存`id_run_capture.mat`，包括原始/低通电压电流、状态、iq保持记录、所有参数更新及诊断，方便分析拒绝原因或残余偏差。它还检查4000次更新、iq保持，以及相对原模型参数的误差。若测试失败请保留该MAT文件，不要通过放宽有效标志来掩盖问题。

可单独运行`test_identification`测试实际MATLAB函数。额外的同速率低通集成测试需要Python的NumPy/SciPy：先运行`python test_lowpass.py`生成合成数据，再在MATLAB/Octave运行`test_pipeline`。生成的MAT文件为测试产物，不是电机仿真记录。

若模型一直停在0，先检查无感切换、PLL锁定和速度；若状态9输出无效，查看状态码及采样记录。保持iq期间若速度无法稳定，不应直接套用稳态公式；需依据实际数据调整实验工作点或等待时间。本版不自动改原模型负载，也不把辨识结果反馈覆盖电机真值或观测器参数。
